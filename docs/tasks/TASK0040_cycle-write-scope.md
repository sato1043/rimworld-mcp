# サイクルが書けるファイルを方針の置き場所に絞る

## 目的

無人で回すサイクルが書き換えられるファイルを、方針ファイルの置き場所
（`.claude/play/<コロニー名>/`）に限る。サイクルが、利用者の確認を経ずに実行の経路
（hooks・設定・スクリプト・状態のファイル）を書き換えられないようにする。

## 目標（起票時の案）

- サイクルの Write と Edit が、`.claude/play/<コロニー名>/` の方針ファイルのほかに
  届かない。届く範囲は許可リストで書く
- 範囲の外へ書こうとした呼び出しは、確認を求めずに断られ、サイクルは理由を返す
- 範囲の守りを外すと落ちる検査を持つ

## 非目標

- ゲームの tool の範囲（TASK0018 の許可リストと除く一覧が受け持つ）
- 対話で遊ぶとき（`rimworld-play` を直に使うとき）の権限

## 問題

- **サイクルは方針ファイルを書くために Write と Edit を持ち、どのファイルにも書ける。**
  TASK0018 は、親がスクリプトを走らせる前と Monitor を張る前に毎回、`.claude/agents`・
  `.claude/skills`・`mcp_server` の `git status --porcelain --untracked-files=all` を
  打ち、1 行でも出たら止まる形で受けている
- **git の確かめの外に、実行の経路が残る。** TASK0018 の自己コードレビューで挙げた
    - 追跡の外の設定: `.claude/settings.local.json` の hooks
    - `~/.claude` の hooks と設定
    - `.git/config`（`git status` 自身が `core.fsmonitor` を走らせる）
    - `__pycache__`（書き換えた `.pyc` が次の `uv run` で読まれうる）
    - 状態のファイル: `usage.json`（上限）・`cycle.json`（印）・`watch.json`（監視の位置）
- **無視されたファイルは git の確かめに現れない。** `.gitignore` は `/.claude/agents/*`
  と `/.claude/skills/*` を除外し、サイクルの定義と 2 つのスキルだけを例外にしている。
  サイクルが新しい定義やスキルをそこへ書いても、`git status` は出さない（`.gitignore` の
  行から読んだ。書いて確かめてはいない）
- **範囲を絞る仕組みは確かめていない。** サブエージェントの定義の `tools` は tool の名前を
  選ぶが、書けるパスは選ばない。permission の規則（パスつきの `Write(...)`）や hook が
  バックグラウンドのサブエージェントにどう効くかは、公式ドキュメントと実機で確かめる
  必要がある
- **ステータスラインの記録の置き場所の境界は、権限の実体では引かれていない。** TASK0018 の
  ステップ 9 は、CLI の判定が読む記録を `.claude/play/` の外
  （`.claude/rate-limits.jsonl`）へ置いた。許可の規則は `Edit(/.claude/play/**)` だが、
  Auto モードでは内も外も同じ classifier の判定になると公式ドキュメントから読める
  （TASK0018 の 2026-10-11 の CP6。classifier の振る舞いは実機で見ていない）。記録は
  追跡の外で、git の確かめにも出ない
    - 記録へ書ける者は、低い値の行を最後に足して起こせる。最後の行が別の 5 時間枠を
      名指すと、新しい行のうち最も高い値を採る規則が働かない（同じ CP6 の再評価層が、
      80 と 85 の後に別の枠の値 1 の行を足して起こす側を再現した）
    - 上限（`usage.json` の `limit`）は `.claude/play/` の内に残るので、記録を外へ出した
      効果は、上限を書き換えられると打ち消される（上の「状態のファイル」と同じ点）
- **ステータスラインは、親の git の確かめを経ずにスキルのコードを走らせる。** CLI の
  準備で `statusLine` を足すと、`record_rate_limits.py` と `usage_rules.py` が
  60 秒ごとに、利用者のセッションの権限で走る。サイクルがこの 2 つを書き換えると、
  親が次の合図で git を打つ前に走りうる（同じ CP6。書き換えて確かめてはいない）
