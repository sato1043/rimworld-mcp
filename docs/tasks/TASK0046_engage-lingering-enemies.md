# マップに残る敵を迎え撃つかを決められるようにする

## 目的

サイクルが、マップに残る敵に対して、迎え撃つか待つかを根拠を持って決められるように
する。

無人で回している間（TASK0018）、敵が離れて残ると、サイクルは起きるたびに「敵は遠い・
入植者は無傷」と読んで指示を出さずに戻る。敵がいる間は追いのサイクルが起き続けるので、
決められないことが、そのまま利用枠の消費になる。

## 目標（起票時の案）

- スキル `rimworld-play` の攻略知識に、残る敵へ出ていくか待つかの判断の基準を、出典と
  確度つきで足す
- 判断に要る読み（敵の人数・武器・今していること・入植者の戦える人数）が、今の tool で
  足りるかを確かめる
- 待つと決めたときに、方針ファイルの「進行中の対応」へ、待つ理由と見直す条件を残す
  書き方を決める

## 非目標

- 追いのサイクルの間隔と、指示の無い追いが続くときの扱い（TASK0037）
- 新しい MCP の tool の追加（読みが足りないと分かったら、別に起票する）
- 防衛の設備（キルゾーン・タレットの配置）の設計

## 問題

- **残る敵を迎え撃つ判断が無い。** 2026-10-10 の TASK0018 の 3 回目の回し直しでは、
  襲撃の 2 人（短弓）が火を付けた後もマップに残った。追いのサイクルは 39 分で 13 回
  起き、どの回も指示を出さなかった。12 人の入植者で迎え撃つ判断は 1 度も無い
- **攻略知識が、離れて残る敵を扱っていない。** `references/basics.md` の「防衛」は、
  土嚢の遮蔽・射手を土嚢の後ろに並べること・序盤は壁と位置取りに資材を使うことを
  書く。敵が攻めて来ずに残るときに、出ていくか待つかは書いていない（2026-10-10 に
  読んで確かめた）
- **出ていく判断は取り返しがつかない。** 入植者の死亡は戻せない。基準（人数の比・武器の
  射程・遮蔽・敵が今していること）は、出典を引いてから書く。Wiki の記述の有無は
  確かめていない
- **敵が今していることを読めるかは確かめていない。** `get_enemies` の説明は、位置・
  健康・武器・今の活動を返すと書く。退いている・火を付けて回る・包囲して待つを
  見分けられるかは、実機で読んでいない
- 火災は、サイクルが tool で消火を指示できない（同じ日の 03:46 の回で、サイクルが
  「利用者に頼むこと」へ積んだ）。火を付けて回る敵を残すと、手の出せない被害が増える
  （推論）

## 裁定記録

- **起票**（2026-10-10・ユーザー）: TASK0018 の 3 回目の回し直しで見つけた「残る敵を
  迎え撃つ判断が無い」を、攻略知識の追加として別に起こす。TASK0037 の非目標「攻略知識の
  変更」は改めない（エージェントの推奨を採った。TASK0018 の裁定記録「迎え撃つ判断の
  置き場所」による）

## stakeholder 未裁定の残課題

- 優先度の 4 軸と `drive`
- 無人の運用で、サイクルが利用者に尋ねずに出撃してよい範囲（例: 人数と武器で優る
  ときだけ・入植者の半分までを出す）
- 待つと決めた回が続くときに、追いのサイクルをどうするかは TASK0037 が決める。両者の
  順序
