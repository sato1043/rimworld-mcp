# 外側のループでコロニーを長く回す

## 目的

対話セッションのコンテキストと利用上限を越えて、LLM がゲーム内の時間を単位に区切った
サイクルでコロニーを運営し続けられるようにする。

## 目標（起票時の案）

- 1 サイクル（TASK0016 のスキルの手順）を外側から繰り返し起動する。`claude -p` を
  スクリプトで繰り返すか、Agent SDK で専用のエージェントにするかを選ぶ
- サイクルの区切りをゲーム内の時間で決め、その間ゲームを進めて待つ
- 待つ間に脅威が届いたら、区切りを待たずに次のサイクルを起こす
- サイクルをまたぐ記憶は、TASK0016 のコロニー方針ファイルに置く
- 1 サイクルのトークンと費用を測り、長時間の運用の見積もりを出す

## 非目標

- スキルの手順と攻略知識の変更（TASK0016）
- 新しい tool の追加（TASK0017）

## 問題

- **ゲーム内の時間を進めて待つ tool が無い。** 待つ側がブリッジ（`127.0.0.1:8080`、
  secret を設定していれば `X-MCP-Token` が要る）を直接引いて tick を見るか、tool を
  足す必要がある
- **割り込みの検出の位置を二重に持ちうる。** `get_events` の位置（`next`）を、ループと
  方針ファイルのどちらが持つかを決める
- **ゲームの窓が前面にないと要求が 15 秒で失敗する。** 「Run in background」を有効に
  する必要がある（README）
- **復帰の経路が要る。** ゲームの停止・ブリッジの接続拒否・セーブの読み直し
  （`get_events` の `reloaded`）で、ループを止めるか続けるかを決める
- **無人で動かすときの権限。** `claude -p` の permission の設定と、書き込みの tool を
  どこまで許すかを決める
- 1 サイクルのトークンと費用は測っていない
