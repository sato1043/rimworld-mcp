# コロニー名を tool で読めるようにする

## 目的

LLM が利用者に尋ねずに、今のセーブのコロニーを名前で識別できるようにする。

TASK0016 のスキルは、セーブごとの方針ファイルを `.claude/play/<コロニー名>/plan.md` に
置く。コロニー名を返す tool が無いため、初回は利用者に尋ねている。外側のループ
（TASK0018）で無人で回すときは、尋ねる相手がいない。

## 目標（起票時の案）

- 今のマップのコロニーの名前（拠点の名前とプレイヤーの勢力の名前）を tool で読めるように
  する
- TASK0016 のスキルの「始める前に」を、名前を tool から取る形へ直す
- upstream へ送れる変更と、この fork の変更に依存する変更を、別のブランチに分ける

## 非目標

- コロニー名を変えること
- 複数のマップ（遠征先・キャラバンの野営地）を持つときの扱いの全般

## 問題

- **コロニー名を返す tool が無い。** `get_game_state`（`/state`）は tick・季節・
  バイオーム・人数・資産だけを返す。`get_world_factions` はプレイヤーの勢力を除く
  （`GameStateReader.GetWorldFactions` の `!f.IsPlayer`）。2026-09-27 に読んで確かめた
- **`get_world_sites` は自分の拠点も返すが、どれが自分かを見分けられない。**
  `Find.WorldObjects.SettlementBases` を勢力で絞らずに返すので、プレイヤーの拠点の名前も
  含まれるはずである。ただし応答の `faction` は勢力の名前で、プレイヤーの勢力の名前を
  知らないと突き合わせられない。今のマップのタイルも応答に無い
- **「コロニー名」が 2 つの名前を指しうる。** ゲームは着陸時にプレイヤーの勢力と拠点の
  それぞれに名前を付けさせる（推論。1.6 で確かめていない）。利用者が答えた
  「カルバーソン休憩所」がどちらにあたるかは確かめていない
- 読む API は、`Faction.OfPlayer.Name` と、今のマップの `Map.Parent`（拠点なら
  `Settlement` の `Label`）が候補である（推論。実装の段で確かめる）
- 足す先は、`get_game_state` の応答へ欄を足すか、新しい tool を足すかで分かれる。
  前者は tool の数を増やさないが、既存の応答の形を変える
